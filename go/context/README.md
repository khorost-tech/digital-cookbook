# go-context — отмена, дедлайны и values на живом стенде

Примеры к статье [«Контекст в Go: отмена, дедлайны, values и анти-паттерны»](https://khorost.tech/go/go-context/) на khorost.tech.
Чистый Go, без docker, только stdlib. Модуль `tech.khorost/go-context-cookbook`.

Идея стенда: **инварианты отмены и values покрыты тестами (`go test ./...` зелёный), а поведение во времени — утечка горутины и распространение отмены — вынесено в запускаемые демо** `cmd/*`.

## Запуск

    go build ./...
    go vet ./...
    go test ./...

    # демо (запускать вручную)
    go run ./cmd/leak        # утечка горутины без отмены vs корректная остановка
    go run ./cmd/propagate   # одна отмена гасит дерево горутин

## Что где

| Подкаталог | Тема | Содержимое (тесты = корректность) |
|---|---|---|
| [`cancel/`](cancel) | Отмена и дедлайны | `WithCancel`/`WithTimeout`, распространение отмены вниз (не вверх), самый ранний дедлайн выигрывает, `WithCancelCause` + `context.Cause` |
| [`values/`](values) | Request-scoped значения | неэкспортируемый тип ключа (без коллизий), геттер с проверкой наличия, перекрытие в дочернем контексте |

## Демо (запускать вручную)

| Команда | Что увидите (сверено живьём) |
|---|---|
| `go run ./cmd/leak` | worker без `ctx.Done()` навсегда виснет на `send`, когда читатель ушёл (горутина не освобождается); тот же worker с `select { case <-ctx.Done(): }` выходит после `cancel()` |
| `go run ./cmd/propagate` | три стадии на общем корневом контексте; один `cancel()` у корня закрывает `Done` у всех — печатают `context canceled` |

## Ключевые инварианты (из тестов)

- ручная отмена ⇒ `ctx.Err() == context.Canceled`; таймаут/дедлайн ⇒ `context.DeadlineExceeded`;
- отмена родителя отменяет детей; отмена ребёнка **не** трогает родителя (вниз, не вверх);
- вложенный дедлайн не может продлить родительский — действует самый ранний;
- `WithCancelCause(cause)`: `ctx.Err()` остаётся `context.Canceled`, а `context.Cause(ctx)` возвращает переданную причину;
- ключ `WithValue` — неэкспортируемый тип (`type ctxKey int`), поэтому пакеты не затирают значения друг друга; геттер возвращает `(v, ok)`, а не паникует.

## Версии

Проверено 2026-07 на **Go 1.26.3** (локально): `go build/vet/test ./...` зелёные, оба демо воспроизводятся. Модуль объявляет `go 1.25.0` (минимум). Зависимостей нет — только `context`, `sync`, `time`, `errors`, `fmt`, `runtime`.
