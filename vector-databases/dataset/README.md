# vector-databases/dataset — общий датасет серии о векторных БД

Корпуса, эмбеддинги и истина точного перебора, на которых построены все стенды
серии `vector-databases`. Статья:
[ANN вглубь](https://khorost.tech/databases/vector-ann-algorithms-deep/).

| корпус | документов | тестовых запросов | зачем |
|---|---|---|---|
| BEIR Quora | 522 931 | 10 000 | основной: размер, при котором заметны перебор, память и построение |
| BEIR FiQA | 57 638 | 648 | гибридный поиск: точные термины, где BM25 сильнее |

Модель — `intfloat/multilingual-e5-small` (384 измерения, векторы нормированы,
префиксы `passage: ` и `query: `), ревизия и версии библиотек — в
`dataset.json`. Модель работает в контейнере, на CPU; внешних API нет.

## Сборка

```bash
python3 scripts/make-dataset.py
```

Около 40 минут на 10 ядрах (почти всё — эмбеддинги Quora). Результат — в
`data/` (в git не хранится):

- `<корпус>/corpus.f32`, `queries.f32` — float32 little-endian, по 384 на строку;
- `corpus.ids`, `queries.ids` — идентификаторы BEIR в том же порядке;
- `gt.rows`, `gt.i32`, `gt.f32` — истина: для 1000 запросов (каждый шаг-й из
  тестовых) номера и скоры 100 ближайших документов точным перебором (`gt/`, Go);
- `manifest.json` — размеры и хеши.

Архивы BEIR проверяются по sha256. Векторы на другом CPU могут отличаться в
последних битах, поэтому сборка сверяется с эталонной выборкой
`reference/<корпус>.sample.f32` (каждая шаг-я строка корпуса, 600 строк — под порог размера файла в репозитории) по
косинусу: не ниже 0,9999. Истина всегда считается от собственных векторов.
