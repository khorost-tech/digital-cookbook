# AI / ML — примеры

Классический ML в проде глазами backend-инженера: признаки и train/serve skew, реестр моделей, онлайн-инференс, дрейф данных, переобучение — на общем датасете платёжного скоринга.

| Стенд | Описание | Статья |
|---|---|---|
| [`ml-dataset/`](ml-dataset/) | Общий датасет серии «Классический ML в проде»: детерминированный поток платежей (2000 пользователей, 120 дней) с захватами аккаунта, новым сегментом трафика с дня 100 и новой схемой мошенничества с дня 105, разметка с задержкой chargeback; эталон признаков «до платежа» и базовая модель | 🔜 скоро |
| [`ml-features/`](ml-features/) | Train/serve skew на PostgreSQL и Feast 0.66: батч-признаки SQL против онлайн-кода по той же спецификации — доли расхождений и перевёрнутых решений при нуле ошибок, атрибуция по источникам; граница PIT в Feast, ttl онлайн против офлайн, отставание материализации, утечка будущего при сборке выборки, один путь без feature store | 🔜 скоро |
| [`ml-registry/`](ml-registry/) | Реестр моделей на MLflow 3.16 с PostgreSQL и DVC 3.67: какая из пяти частей версии переворачивает решения (срез данных, версия признака, препроцессинг вне артефакта), артефакт skops под тремя старыми scikit-learn, стадии против алиасов, алиас перенесён — запущенный сервинг обслуживает старую версию, сверка «загружено против реестра»; данные в DVC и прямо в git | 🔜 скоро |
