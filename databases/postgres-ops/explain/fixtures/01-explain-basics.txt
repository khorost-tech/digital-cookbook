 Seq Scan on orders  (cost=0.00..56959.00 rows=31324 width=36)
                     (actual time=221.581..231.097 rows=30715.00 loops=1)
   Filter: ((status = 'paid'::text) AND (created_at > (now() - '30 days'::interval)))
   Rows Removed by Filter: 1969285
   Buffers: shared read=16959
 Planning Time: 0.035 ms

# Читать:
#   cost=0.00..56959.00 — оценка стоимости (старт..итог), в абстрактных единицах.
#   rows=31324 (оценка) против actual rows=30715 — статистика свежая, оценка точна.
#   Rows Removed by Filter=1969285 — сколько строк отброшено предикатом (весь seq scan).
#   Buffers: shared read=16959 — все 8-КБ страницы прочитаны с диска (холодный кеш).
#   Второй прогон дал бы shared hit (из кеша).
