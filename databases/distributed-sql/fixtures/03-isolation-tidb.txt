--- write skew: for-update ---
# cmd: docker run --rm --network dsql dsql-bench skew -engine tidb -iso for-update
T1  START TRANSACTION                                    -> ok
T2  START TRANSACTION                                    -> ok
T1  SELECT @@transaction_isolation                       -> REPEATABLE-READ
T1  SELECT id FROM oncall WHERE on_call = 1 FOR UPDATE   -> 2 строк(и) под блокировкой
T2  SELECT id FROM oncall WHERE on_call = 1 FOR UPDATE   -> ждёт блокировку, идём дальше
T1  UPDATE oncall SET on_call = 0 WHERE id = 1           -> ok
T2  UPDATE oncall SET on_call = 0 WHERE id = 2           -> в очереди: предыдущий шаг этой транзакции ещё ждёт
T1  COMMIT                                               -> ok
T2  (ранее ждавший шаг)                                  -> 1 строк(и) под блокировкой
T2  (ранее ждавший шаг)                                  -> не выполняется: транзакция видит дежурных 1, уходить нельзя
T2  COMMIT                                               -> ok
итог: на дежурстве 1 — инвариант цел
