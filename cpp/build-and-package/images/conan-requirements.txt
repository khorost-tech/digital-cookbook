# Conan и ВСЕ его зависимости — по версии и по контрольной сумме.
#
# ЗАЧЕМ ЭТОТ ФАЙЛ. Раньше плечо conan ставилось строкой
# `pip3 install conan==2.32.0`. Закреплён в ней был ровно один пакет из
# шестнадцати: версия самого conan. Пятнадцать его зависимостей приезжали
# те, что окажутся свежими в день сборки, — то есть внутрь замеряемой
# сборки входил подвижный набор, о котором фикстура не говорила ничего.
#
# КАК СНЯТ. `pip3 download conan==2.32.0` ВНУТРИ базового образа стенда,
# затем sha256 каждого колеса. Внутри образа — не для удобства: три колеса
# из пятнадцати собраны под конкретный интерпретатор и архитектуру
# (cp313, x86_64), и снятые где-то ещё они не совпали бы с тем, что pip
# выберет здесь. Базовый образ закреплён дайджестом, поэтому интерпретатор
# зафиксирован вместе с ним и набор ему соответствует.
#
# ЧТО ЭТО ДАЁТ И ЧЕГО НЕ ДАЁТ. Даёт: подмена любого колеса становится
# ГРОМКОЙ — pip останавливается на несовпадении суммы. Не даёт:
# работоспособности на другой архитектуре. Там сверка не пройдёт, и это
# правильный исход — она скажет вслух, что закрепление снято не для той
# машины, вместо того чтобы молча поставить другой файл.
#

# точную версию. Забыть здесь зависимость нельзя молча: pip откажется
# ставить, назвав недостающее имя.
